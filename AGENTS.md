# Agent instructions

This repo is the Mob Trophies add-on for Minecraft Bedrock. The packs under
`packs/` and the installable `dist/MobTrophies.mcaddon` are generated by
`tools/build.py`. Read `README.md` for the full layout.

## Always rebuild after changing the add-on

After **any** change that affects the add-on, rebuild before you finish or
commit:

```sh
python3 tools/build.py
```

This counts as a change to the add-on:

- `tools/mobs.py` (head art, sizes, palettes, extra cubes, mob list)
- `tools/build.py` (block, geometry, texture, manifest or packaging logic)
- `packs/MobTrophies_BP/scripts/main.js` (the only hand-written pack file;
  the build copies it into the `.mcaddon`, so the download is stale until you
  rebuild)

The build must finish without errors. It validates the art and checks that
every head fits inside its block. If it fails, fix the cause and run it again.
Never hand-edit generated files to get around a failure.

If you changed head art, models or textures, also refresh the preview and
look at it to check the result:

```sh
python3 tools/preview.py   # writes docs/heads_preview.png
```

Then commit the regenerated files together with your source change,
including `packs/`, `dist/MobTrophies.mcaddon` and (if refreshed)
`docs/heads_preview.png`. The `.mcaddon` is committed on purpose so it can be
downloaded straight from GitHub onto a phone or tablet.

## Do not edit generated files

Everything under `packs/` except `packs/MobTrophies_BP/scripts/main.js` is
overwritten by the build. Make changes in `tools/mobs.py` or `tools/build.py`
instead.

## Setup

The build needs Python 3 and Pillow (`pip install pillow`).
